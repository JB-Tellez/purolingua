<objective>
Fix BUGFIX-02: the `allDecksEmpty` check in `StudySession.handleAnswer` uses the current deck's `cards` array as a proxy for ALL decks, causing wrong indices for every other deck. It also uses language-neutral `DECK_IDS` (covering both Italian and Spanish). Fix by: (1) extracting a shared `DECK_MAP` to `src/data/deckMap.ts`, (2) importing it in StudySession to get each deck's own card array, (3) scoping the deck list to the current language via `deckMetadata.filter(d => d.lang === lang)`.

Purpose: Users in A1-only mode will not see the all-done screen prematurely when only one deck is finished while others still have due A1 cards.
Output: New `src/data/deckMap.ts` (shared card map); patched `src/app/[lang]/[deck]/StudySession.tsx` with correct `allDecksEmpty` logic; extended StudySession tests covering both bug scenarios.
</objective>
