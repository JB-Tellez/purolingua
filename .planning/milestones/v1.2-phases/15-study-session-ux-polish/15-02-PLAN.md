<feature>
  <name>FeedbackMessage</name>
  <files>src/components/FeedbackMessage.tsx, src/__tests__/components/FeedbackMessage.test.tsx</files>
  <behavior>
    FeedbackMessage props: `state: 'correct' | 'incorrect' | 'heard' | 'notRecognized' | null`

    - state=null → renders nothing (returns null)
    - state='correct' → renders element containing t('correct'), green styling (text-green-600 or similar)
    - state='incorrect' → renders element containing t('incorrect'), red styling (text-red-500 or similar)
    - state='heard' → renders element containing t('heard'), neutral styling (text-blue-500 or similar)
    - state='notRecognized' → renders element containing t('notRecognized'), neutral/muted styling (text-gray-500)

    Test cases (exact assertions):
    - render with state=null → expect(container.firstChild).toBeNull()
    - render with state='correct' → expect(screen.getByText('correct')).toBeInTheDocument()
    - render with state='incorrect' → expect(screen.getByText('incorrect')).toBeInTheDocument()
    - render with state='heard' → expect(screen.getByText('heard')).toBeInTheDocument()
    - render with state='notRecognized' → expect(screen.getByText('notRecognized')).toBeInTheDocument()

    Note: with mock `useTranslations: () => (key) => key`, t('correct') returns the literal string 'correct', etc.

    Styling: inline component (no overlay, no fixed positioning). A small pill or plain text with `role="status"` for accessibility.
    Use aria-live="polite" so screen readers announce the feedback without interrupting.
  </behavior>
  <implementation>
    After tests pass:
    - 'use client' directive at top
    - Import useTranslations from 'next-intl'
    - Props: `{ state: 'correct' | 'incorrect' | 'heard' | 'notRecognized' | null }`
    - Return null when state is null
    - Map state to i18n key (correct→'correct', incorrect→'incorrect', heard→'heard', notRecognized→'notRecognized')
    - Map state to Tailwind color class:
      - correct: text-green-600
      - incorrect: text-red-500
      - heard: text-blue-500
      - notRecognized: text-gray-500
    - Render: `<p role="status" aria-live="polite" className={`text-sm font-medium text-center ${colorClass}`}>{t(key)}</p>`
  </implementation>
</feature>
