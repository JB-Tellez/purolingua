## Critical Gaps (Blockers)

### Gap 1 — Phase 13 Missing VERIFICATION.md

### Gap 2 — Phase 14 Missing VERIFICATION.md

Phase 14 (Voice Recognition) has no `14-VERIFICATION.md`. All 14 VOICE requirements cannot be formally verified. All 14 VOICE tests currently pass (57/57 total), and SUMMARY.md files for Plans 01 and 02 list these requirements as completed. The integration checker confirmed voice wiring is correct. However, the verification gate was never run.

**Blocked requirements:** VOICE-01 through VOICE-14

### Gap 3 — ROUTE-02: Live Due-Count Badges Not Implemented

The requirement states deck grid tiles should show "due-count badges" — how many cards are due today per deck. The Phase 12 VERIFICATION.md claimed this as satisfied. However, the integration checker found that `src/app/[lang]/page.tsx` never calls `useSRS()`. Deck tiles render static card count (e.g., "40 carte" from i18n key `deckCardCount`), not a live due count. The `.due-badge` CSS class exists in `style-reference.css` but is not applied to any element.

**Affected file:** `src/app/[lang]/page.tsx`
**Fix:** Import `useSRS(lang)` in the deck grid page, compute due cards per deck, and render the count in a badge on each tile.

### Gap 4 — UX-05: allDecksEmpty Defect in A1-Only Mode

The all-done screen triggers when `allDecksEmpty` returns true. The check at `StudySession.tsx` lines 198–200 iterates `DECK_IDS.every(id => filteredCards.every((_, i) => !isCardDueForDeck(id, i)))`. The problem: `filteredCards` is the current deck's Card[] filtered by `activeLevels`. In A1-only mode with 20 filtered cards, indices 0–19 are checked for all 8 decks. Cards at indices 20–39 (which hold A2 cards in all decks) are never queried — this makes the all-done check always return true when only A1-level filter is active, even when A2 cards in other decks are due.

**Affected file:** `src/app/[lang]/[deck]/StudySession.tsx` lines 198–200
**Fix:** The allDecksEmpty check must load each deck's card array separately (or use a per-deck card count) to check all indices for each deck, independent of the current deck's filtered card pool.
