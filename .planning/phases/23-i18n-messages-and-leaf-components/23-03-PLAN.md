<!-- Types and i18n keys used by SiteHeader -->

From app/types/index.ts:
```typescript
export type Lang = 'it' | 'es'
```

i18n keys used in SiteHeader:
- t('nav.logo')  → "Italiano" (it) / "Español" (es)
- t('nav.back')  → "← Indietro" (it) / "← Volver" (es)
- t('nav.reset') → "Reset" (both)

Path-depth logic (locked decision from CONTEXT.md):
```typescript
const route = useRoute()
const segments = computed(() => route.path.split('/').filter(Boolean))
const onDeckPage = computed(() => segments.value.length >= 2)
const backHref = computed(() => '/' + segments.value.slice(0, -1).join('/'))
```

Path examples:
  '/it/'          → segments=['it']        → length=1 → no back button
  '/it/rephrase'  → segments=['it','rephrase'] → length=2 → show back → backHref='/it'
  '/it/rephrase/daily' → segments=['it','rephrase','daily'] → length=3 → show back → backHref='/it/rephrase'

NuxtLinkLocale (auto-registered by @nuxtjs/i18n):
```vue
<NuxtLinkLocale to="/" :locale="'es'">...</NuxtLinkLocale>
<NuxtLinkLocale to="/" :locale="'it'">...</NuxtLinkLocale>
```

SiteHeader props: `{ lang: 'it' | 'es' }`
Receives lang as prop — parent (app.vue or layout) passes `useI18n().locale.value as Lang`

Reset handler (locked decision):
```typescript
function handleReset() {
  localStorage.removeItem(`${props.lang}-progress`)
  window.location.reload()
}
```
No import.meta.client guard needed — handleReset() is click-triggered (client-only).

Dropdown toggle:
```typescript
const dropdownOpen = ref(false)
```
