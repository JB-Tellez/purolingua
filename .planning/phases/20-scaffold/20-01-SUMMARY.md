## Decisions Made
- **Inlined route constants in nuxt.config.ts:** `src/data/decks.ts` and `src/data/qa/*.ts` all use `@/types` TypeScript alias which is not available at Nuxt config evaluation time. DECK_IDS and SCENARIO_IDs are inlined directly in nuxt.config.ts with a comment noting they must stay in sync with src/data/.
- **langDir relative path:** Used `'../messages'` (relative to srcDir `app/`) rather than an absolute path — i18n v10 warns that absolute paths don't work in production.
- **jsdom for unit environment:** setup.ts sets `window.localStorage` and `window.SpeechRecognition` globals; switching to `node` environment causes `ReferenceError: window is not defined`. Using jsdom maintains compatibility with existing test setup.
