<objective>
Fix the level filter — badge reactivity regression introduced in 16-01.

Toggling A1/A2 chips on the home page does not update the due-count badge because
LevelFilterChips and DeckGrid each call useLevelFilter independently. React useState is
per-component-instance, so the two hook calls produce independent state objects. The chip
toggle updates LevelFilterChips's copy only; DeckGrid's copy never changes.

Purpose: Deck card due-count badges must immediately reflect the active level selection so
users see accurate study counts as they switch between A1-only and A1+A2 filters.

Output:
- src/app/[lang]/page.tsx — useSRS + useLevelFilter lifted into LangPage; activeLevels +
  setActiveLevels threaded as props into DeckGrid and LevelFilterChips
- src/components/LevelFilterChips.tsx — hook calls removed; props accepted instead
- src/__tests__/components/DeckGrid.test.tsx — Test E added confirming badge responds to
  activeLevels change between renders
</objective>
